이 화면이 하는 일

들어오는 길은 둘이다. 앱을 직접 열면 로그인 화면 아래 「초대 코드로 가입」에서 휴대전화번호와 8자리 초대 코드를 넣는다(/join). 초대 링크를 열면 토큰이 /invite#token=… 에 실려 와 코드 입력을 건너뛴다. 토큰을 # 뒤에 두는 것은 재설정 링크와 같은 방식으로, 서버 접근 기록에 토큰이 남지 않게 하려는 것이다. 초대 토큰(43자)은 사람이 칠 수 없어 짧은 코드를 따로 둔다 — JOIN-7. 링크로 오면 코드 입력이 없어 단계가 셋(초대 확인 · 계정 등록 · 가입 완료)이다.

초대를 확인하고 계정을 등록하면 계정은 초대의 직원 레코드에 바로 이어진다 (운영 정책 JOI-04·05). 본인인증도, 번호가 어긋날 때 관리자 확인을 기다리는 단계도 없다. 가입과 함께 근로계약서가 자동으로 발송되고(운영 정책 JOI-09) 홈 위에 날인 요청 팝업이 뜬다. 가입 때 넣은 이름·생년월일·성별·외국인 여부가 계약서와 다르면 날인 전 본인 대조에서 걸려 수정 요청으로 이어진다(운영 정책 JOI-10).

이미 계정이 있는 사람은 새로 가입하지 않는다. 초대를 확인하면 「이미 계정이 있습니다」와 로그인 버튼이 뜨고, 로그인한 뒤 앱 안에서 소속 추가 확인(전에 일한 근무지면 복귀 확인)이 뜬다(운영 정책 JOI-02). 가입을 이미 마친 초대를 다시 열면 로그인 화면이 대신 뜬다.

초대 코드는 틀린 쪽을 알려 주지 않는다

번호와 코드가 맞지 않으면 「휴대전화번호나 초대 코드를 다시 확인해 주세요」 한 줄만 보인다. 어느 칸이 틀렸는지, 그 번호로 초대가 있는지는 알리지 않는다 — 알려 주면 남의 번호로 초대가 있는지 떠볼 수 있다. 같은 이유로 두 칸을 함께 빨갛게 한다. 여러 번 틀리면 입력을 잠그고 남은 시간을 보인다. 같은 번호로 5회 틀리면 30분 잠그고, 접속 IP 기준 제한도 따로 둔다. 관리자에게 재발송을 받으면 새 코드로 바로 다시 시작한다(JOIN-7).

개인정보는 수락 전과 후 모두 선을 긋는다

소속 추가 확인은 수락하기 전까지 상대가 어느 계정인지 알려 주지 않는다. 보이는 건 초대한 사업자·점포와 고용 형태뿐이다. 수락해도 넘어가는 건 계정 가입 정보 다섯 가지(이름·휴대전화번호·생년월일·성별·외국인 여부)뿐이고(운영 정책 JOI-08), 다른 데서 어떤 계약을 맺었고 얼마를 받았고 언제 출근했는지는 이 점포로 옮겨지지 않는다. 관리자 쪽도 마찬가지다 — 소속 확인 대상 계정의 실명과 다른 소속은 관리자도 볼 수 없다. 두 화면이 같은 선을 지킨다.

인적사항, 이제는 직원이 적는다

계정 등록 화면에서 이름·휴대전화번호·생년월일(8자리)·성별·외국인 여부를 직원이 직접 넣는다(운영 정책 ACC-23). 휴대전화번호만은 읽기 전용이다 — 코드로 왔으면 코드와 함께 확인된 번호, 링크로 왔으면 그 초대(근로계약서)의 번호를 채운다. 계정 번호는 매칭 키라, 고칠 수 있으면 남의 번호로 가입해 그 사람의 다음 초대를 막을 수 있다. 번호가 틀리면 관리자가 날인 전에 당사자 정보를 고쳐 다시 초대한다(운영 정책 CTR-28). 생년월일은 가입한 뒤 고칠 수 없어 칸 아래에 적어 둔다(운영 정책 ACC-13). 근로계약서에 들어갈 주소도 관리자가 적지 않고 직원이 검색으로 골라 상세주소만 넣는다(운영 정책 ACC-20) — 아래 JOIN-4.

가맹 점포는 본사 제공 동의를 따로 받는다

가맹 점포 직원의 근무 정보를 가맹본부가 개인 단위로 보려면 직원의 선택 동의가 있어야 한다 (운영 정책 ATT-30, 2026-09-30). 가맹 점포 레코드로 가입할 때와 가맹 점포의 소속 추가 확인·복귀 확인을 수락할 때 받는다. 직영 점포에는 없다.

거부해도 가입과 근무는 그대로다. 그때 본사에는 점포별 숫자로만 보인다. 이 말을 체크 옆에 같이 적어 둔 것은, 선택 동의가 필수처럼 읽히면 동의가 동의가 아니게 되기 때문이다. 동의 문구는 법무 답에 따라 바뀔 수 있다(ATT-8).

만 19세 미만은 가입이 멈춘다

초안에서 먼저 막는다 — 관리자가 근로계약서 초안(종이 계약 포함)에 적는 생년월일로 만 19세 미만을 거른다. 이 화면은 두 번째 확인이다. 초안의 생년월일이 틀렸더라도 가입 때 직원이 넣은 값이 가입 시점 기준 만 19세 미만이면 계정을 만들지 않고 거기서 멈춘다 (운영 정책 ACC-22, 2026-09-30). 다음 단계 버튼 없이 닫기만 두고, 근무지 관리자에게 알리라고 안내한다. 미성년 직원의 근로계약·출퇴근·급여는 점포가 시스템 밖에서 따로 관리한다.

소속 추가 확인과 복귀 확인은 나이를 다시 보지 않는다 — 이미 가입한 계정이라 확인할 것이 없다. 이 판단이 맞는지는 법무가 확인한다.
