# 출퇴근 유저플로우를 현재 규칙으로 맞춘다

근거: 2026-11-09 재영 지시(기획 세션 header 전달). `docs/flow/attendance` 가 2026-09-28 뒤로 고쳐지지 않아 납품 문서(유저플로우)가 현재 규칙과 어긋난다. 기준은 공통 용어집과 운영 정책 ATT 장이다.

## 고칠 것

- 반경 밖 출근도 받고 확인 필요를 붙인다(운영 정책 ATT-14).
- 위치 오차 판정 간선 · 보기 · 카드 문구를 없앤다(운영 정책 ATT-04).
- 확인 필요 사유 넷을 드러낸다: 반경 밖 출근 · 반경 밖 퇴근 · 위치 조작 감지 · 근무 12시간 초과(운영 정책 ATT-19).
- 위치 조작 감지: 출근은 막고 퇴근은 확인 필요로 받는다(운영 정책 ATT-21).
- 위치정보 동의 거부 · 철회 · 일시 중지: 「근무지 관리자에게 문의」 안내 뒤 관리자 대신 등록(운영 정책 ATT-06 · 20 · 23 · 26). 휴대전화 위치 권한을 끈 경우는 권한을 켜도록 안내만 한다(운영 정책 ATT-03).
- 근무지 선택 노드를 없앤다. 앱에서 고른 근무지로 등록한다(운영 정책 ATT-07).
- 위치는 버튼을 누를 때 다시 읽어 판정하고, 판정은 휴대전화에서 한다(운영 정책 ATT-05 · 22).
- 출근은 바로 기록하고 퇴근과 반경 밖은 확인 시트를 거친다(운영 정책 ATT-13 · 14).
- 막히는 경우: 체결 완료 계약 없음 · 열린 출근 중복 · 근무지 위치 없음(운영 정책 ATT-08 · 09 · 36).

## 하는 일

- `attendance.workflow.json` 을 고치고 archify `deliver` 로 `attendance.html` 을 다시 만든다. `visual-check` 로 증거 파일을 갱신한다.
- `docs/flow/index.html` 의 출퇴근 카드 번호 설명만 맞춘다.
