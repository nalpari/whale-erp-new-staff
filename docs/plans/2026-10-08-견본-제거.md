# 견본 화면 걷어 내기 (2026-10-08)

## 왜

api 의 견본(예제) 테이블·API(`items`·`stock_movements`·`staff`·`customers`)와 견본 로그인이
지워진다(2026-10-07 재영 결정). staff 앱의 견본 화면은 그 API 를 부르는 데모라 같이 걷어 낸다.
직원 근무 앱 로그인은 3팀이 `accounts` 로 새로 만든다. api 와 같은 날 커밋한다.

## 지울 것

| 대상 | 이유 |
|---|---|
| `src/app/items/` | 견본 품목 목록. `GET /items` 를 부른다 |
| `src/app/login/` | 견본 로그인 화면·액션. `POST /auth/staff/login` 을 부른다 |
| `src/lib/api.ts` 의 `Item`·`listItems`·`login`·`AuthUser.type`·`TokenResponse`·`logout` | 견본 API·인증에만 쓰인다 |
| `src/app/layout.tsx` 의 IBM Plex 글꼴 두 벌과 `DIRECTION_CONTRACT` | 견본 콘솔(계근대 월드)용 |
| `src/app/globals.css` 의 계근대 토큰·다크 바탕·`.slot`·`.lit`·`.settle` | 견본 콘솔용. 직원앱 토큰(`--color-staff-*`)과 화면 이동 슬라이드는 남긴다 |
| `public/brand/coil-yard.webp`(·`.txt`) | 견본 로그인 사진 |

## 남길 것

- `src/lib/api.ts` 의 `API_BASE_URL` 읽기(`baseUrl`), fetch 틀(`request`), `ApiError`, Nest 오류 메시지 처리,
  세션 쿠키 읽기(`getSession`)·쓰기(`setSession`)·지우기(`clearSession`). 새 로그인이 그대로 쓸 수 있게 내보낸다.
- `.env.*` 의 `API_BASE_URL`.

## 임시 첫 화면

`/` 는 `/design` 으로 보낸다. 직원 근무 앱 화면이 생길 때까지 볼 수 있는 것은 디자인 견본과 화면 목업뿐이다.
로그인이 생기면 첫 화면을 그쪽으로 바꾼다.

## 함께 고칠 문서

- `PRODUCT.md` — 직원 근무 앱 기준으로 다시 쓴다. 근거는 `docs/mockup` 과 `okf` 뿐.
- `DESIGN.md`·`okf/whale-erp-staff.md` — 「루트는 계근대(다크) 콘솔」 서술을 지운다.
- `okf/log.md` — 한 줄.
