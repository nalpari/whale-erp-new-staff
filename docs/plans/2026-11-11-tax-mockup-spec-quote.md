# 신고 정보 목업 근거 칸의 명세 인용을 지금 원문으로 바꾼다

근거: 2026-11-11 재영 지시(기획 세션 header 전달). 목업 `docs/mockup/app/tax.html` 근거 칸이 「근로계약서 초안 작성과 발송」 명세를 ID로 인용하고 있다. 인용한 문장(「암호화 저장·마스킹 노출·신고 시 원본 사용」)은 그 명세에 더 이상 없다. 게다가 「마스킹 노출」은 급여 계좌까지 가리는 것처럼 읽혀 운영 정책 TAX-07과 어긋난다.

## 고칠 것

목업 근거 칸의 인용 한 줄을 Manyfast 원문(2026-11-11 읽음) 세 줄로 바꾼다. 라벨에는 ID 대신 명세의 한글 이름을 적는다.

- 「근로계약서 입력 항목과 계약 조건」 비즈니스 규칙: 수집 목적 표시와 별도 동의를 두지 않는다는 문장.
- 같은 명세 비즈니스 규칙: 「주민등록번호는 암호화해 저장하고, 관리자 웹에는 마스킹한 값만 표시하며, 4대보험 신고 또는 원천징수 서류를 만들 때만 원본을 사용한다.」
- 「근무지별 신고 정보 조회와 수정」 권한: 관리자 웹이 급여 계좌를 가리지 않고 보인다는 문장. 원문 끝의 출처 괄호(정책 번호 · 날짜 · 사람 이름)는 빼고 문장까지만 인용한다.

## 하지 않는 것

- 근거 칸 밖의 목업, 데모, 앱 문구.
- 목업의 다른 ID 인용(위쪽 설명 주석, 쟁점 블록의 `gap__ref`)은 이번 지시 범위가 아니다.
