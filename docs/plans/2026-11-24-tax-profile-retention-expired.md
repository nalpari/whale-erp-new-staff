# 퇴직 근무지 신고 정보 — 보존 기간이 지났음을 알리기 (WHALEERP-772)

2026-11-24. api 짝 브랜치(trapinch)가 신고 정보 조회에 `expired` 를 더한다 — 퇴직일이 파기 기준(퇴직 + 3년, 운영 정책 RET-01 · TAX-08)보다 앞이면 true, 그때 `taxProfile` 은 늘 null.

## 바꾸는 것

- 내 정보 › 소속 근무지 › 퇴직 카드 › 신고 정보: `expired` 면 「입력한 신고 정보가 없습니다」 대신 보관 기간이 지났다는 사실을 보이고, 「조회만 할 수 있습니다」 안내는 두지 않는다(볼 것이 없다). 넣은 적 없는 퇴직 근무지(`expired: false`)는 지금 그대로.
- 문구는 2안 캡처로 정했다 — **B안, 2026-11-24 재영**: 제목 「신고 정보 보관 기간이 지났습니다」, 덧말 「퇴직 후 3년이 지나 이 근무지의 신고 정보를 보관하지 않습니다.」(A안 「보관 기간이 지나 신고 정보를 지웠습니다」는 넣은 적 없이 기한이 지난 경우에 사실과 달라 고르지 않음).
- 근로계약서 · 급여명세서 빈 상태는 이번에 고치지 않는다(확인 결과는 WHALEERP-772 댓글).
- `expired` 가 없는 옛 api 응답이면 false 로 본다.

## 검증

- `src/lib/tax-profile.test.ts`: 빈 상태 문구 — expired · 넣은 적 없음 · 옛 응답.
- tsc · lint, 로컬(api 브랜치 + 일회용 DB)에서 기한 지난 퇴직 근무지 · 넣은 적 없는 퇴직 근무지 화면 캡처.
