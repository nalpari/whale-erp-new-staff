# 로그인 · 품목 목록

## 범위와 모드
`/login` 과 `/items`. 둘 다 Operate. 로그인은 이 콘솔의 첫인상을 지고, 목록은 재고를 읽는 일만 한다.

## 관객과 일
사무실 관리자(데스크톱)와 현장 직원(태블릿)이 같은 화면을 쓴다. 하는 일은 둘뿐이다: 들어간다, 재고를 읽는다.

## 내용과 제약
API 가 주는 것만 말한다. 품목은 SKU / 품목명 / 단위 / 재고 네 값이고, 재고 상태로 화면이 주장할 수 있는 것은 0 과 0 아님뿐이다. 액세스 토큰은 15분이고 갱신 장치가 없어 만료되면 로그인으로 돌려보낸다. API 에 CORS 가 없어 호출은 전부 서버 사이드다.

## 방향과 기억할 순간
계근대(weighbridge). 화면 전체가 계측 장비 전면이고, 측정된 수치만 앰버로 발광한다. 기억할 순간은 목록이 뜰 때 재고 숫자가 위에서부터 순서대로 켜지는 것. 재고 0 은 붉은 배지가 아니라 소등(발광 없음)으로 남되, 판독은 가능해야 한다.

## 색의 규칙
앰버는 측정값에만, 초록은 조작(기동·포커스·캐럿)에만, 붉은색은 경보에만. 이 규칙이 깨지면 숫자가 화면의 주인공이 아니게 된다.

## 승인된 comp
`.impeccable/mocks/comp/login-b-yard.webp` (로그인 구성, 사용자가 comp 라운드에서 승인).
품목 화면은 같은 월드의 `.impeccable/mocks/comp/items.webp` 를 기준으로 삼는다.

## 미결
- 품목 등록·수정·재고 이동 화면은 아직 없다. 밴드 행을 눌러 이동 이력을 펼치는 구조가 다음 자리다.
- 목록에 검색·정렬·페이지네이션이 없다. 총 건수 API 가 없어 페이지네이션 UI 는 아직 정직하게 그릴 수 없다.
